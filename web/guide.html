Kết nối đúng chân. Xem dữ liệu thật.

Áp dụng cho module tím trong ảnh có hàng chân VIN, 3V3, GND, SCL, SDA, CS, SA0. Rút USB trước khi đấu dây.

1. Đấu SPI vào ESP32-S3

SA0 là MISO khi chạy SPI: nối GPIO 7. Để trống hàng lỗ OCS, INT2, INT1, SCX, SDX. Không nối CS cố định lên nguồn; không nối SA0 xuống GND. Giữ dây ngắn.

2. Nạp firmware Kalman

pio run -e bmi160 -t upload

Nếu có nhiều cổng: thêm --upload-port COMx. Đóng Serial Monitor trước khi mở cổng trên web.

3. Xem dữ liệu trực tiếp

Cài phụ thuộc lần đầu: python -m pip install -r requirements-visualizer.txt. Python PlatformIO đã có pyserial.

  1. Chạy python live_bmi_visualizer.py, mở http://localhost:8765 bằng Chrome, Edge hoặc trình duyệt tích hợp VS Code.
  2. Python tự nhận cổng USB-UART của ESP32-S3. Không cần hộp chọn cổng của trình duyệt. Nếu có nhiều USB-UART, chọn COM trên dashboard rồi bấm Kết nối cảm biến.
  3. Chờ tín hiệu; giữ cảm biến yên để bộ lọc khởi tạo góc.
  4. Chọn Gốc + Kalman để so sánh; bấm Bắt đầu ghi CSV để thu dữ liệu và Dừng & tải CSV để lưu.

Cột button_state trong CSV: 1 = nhấn, 0 = thả, chống dội 30 ms. Cắt rep tại cạnh 0 → 1; giữ nút vẫn là một mốc. Nhấn nút không khởi tạo lại cảm biến. Dashboard có đồ thị nút và vạch đỏ đánh dấu lần nhấn. Nạp firmware mới, Ctrl+F5 để nhận cột thứ 29; firmware cũ chưa có trạng thái nút.
Xem demo chỉ mô phỏng giao diện. Góc roll/pitch dùng accel + gyro, không có hướng yaw tuyệt đối. Độ tin cậy giảm khi chuyển động mạnh hoặc pitch gần ±90°. Đồ thị tạm dừng vẫn nhận và ghi mẫu.

Nếu chưa thấy tín hiệu

Muốn chỉ định cổng ngay lúc chạy: python live_bmi_visualizer.py --serial-port COM10. Bấm Ngắt kết nối để nhả cổng trước khi nạp firmware; bấm kết nối để mở lại. Rút/cắm USB sẽ tự thử nối lại. Nếu mở index.html qua một server khác không có API Python, web dự phòng Web Serial và cần cấp quyền cổng.

  • Đóng các chương trình khác đang giữ cổng COM, kiểm tra cáp USB có dữ liệu.
  • Mở nhật ký trên dashboard; CHIP_ID invalid thường cần kiểm tra nguồn, CS và SA0/MISO.
  • Đảm bảo đã nạp firmware mới để có đường Kalman và góc nghiêng. Web vẫn đọc được CSV 17 cột của bản cũ.
